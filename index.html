규칙 1~8 · 여러 파일 · ZIP 다운로드

엑셀 옵션 일괄 변환기

A파일 여러 개와 B양식 하나를 선택하고 결과를 ZIP으로 다운로드합니다.

적용 규칙

  1. B 상단 1~3행 보존
  2. B A4부터 품번코드 입력
  3. 각 A파일의 마지막 단품코드 다음 번호부터 새 코드 생성
  4. C열: 색상:패션의류/잡화 사이즈:수량
  5. D열: 앞항목:뒤항목 → 뒤항목:앞항목:1개
  6. A D4부터 모든 옵션을 수집하고 누락 여부 검증
  7. B 기존 4·5·6행 전체 삭제 후 4행부터 순서대로 입력
  8. A~D가 모두 채워진 행의 E열에 숫자 100 입력

이 페이지는 기존 등록용 B양식을 사용하는 버전입니다. 택1·원본 재고 복사·L/M열 자동 입력 기능은 적용하지 않습니다.

Ctrl 또는 Shift로 여러 파일을 선택하세요.

A2가 품번코드[필수]인 기존 등록용 양식을 사용합니다.

프로그램을 준비하고 있습니다.

파일별 결과

번호 A파일 상태 옵션 수 결과 파일명 상세

A 원본

B 결과

각 파일의 첫 번째 시트 / 제목 2행 / A 데이터 시작 4행을 사용합니다. B는 기존 4~6행 삭제 후 4행부터 연속 입력합니다. 미리보기는 최대 100개이며 결과에는 전체 옵션이 포함됩니다.

파일마다 B양식 원본을 새로 사용합니다. 실패한 파일은 결과 엑셀에서 제외하고 처리결과.txt에 기록합니다. 결과 이름이 같으면 (2) 등을 붙여 덮어쓰기를 방지합니다.

기존 7행 이후의 행은 3행 위로 이동합니다. 행 삭제 시 참조가 복잡해지는 수식·표·그림·메모·이름 정의 등은 안전을 위해 처리를 중단합니다.

단품코드는 파일별로 독립 생성합니다. 같은 상품이 여러 A파일에 포함되면 파일 간 코드가 겹칠 수 있으므로 업로드 전에 확인하세요.

파일은 브라우저에서 처리하며 서버로 전송하지 않습니다. 라이브러리 로딩에는 인터넷 연결이 필요합니다. 원본을 보관하고 결과를 확인한 후 사용하세요.
