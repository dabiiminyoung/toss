새 B양식 · 원본 재고 복사 · 여러 파일 ZIP

엑셀 옵션 일괄 변환기

원본 행 위치를 유지하고 옵션·재고·연결상품코드를 함께 변환합니다.

적용 규칙

  • B 상단 1~3행 보존 · 행 삭제 및 이동 없음
  • A 원본 행 번호 그대로 B에 입력
  • A열: 품번코드 복사
  • B열: 각 A파일의 마지막 단품코드 다음 번호부터 생성
  • C열: 색상:패션의류/잡화 사이즈:수량
  • D열: 앞항목:뒤항목 → 뒤항목:앞항목:1개
  • E열: 같은 A 원본 행의 가상재고 복사 — 숫자 0 포함
  • L열: A·B·C가 모두 채워진 데이터 행에 숫자 2
  • M열: 같은 A 원본 행의 연결상품코드 복사
  • 출력 파일명: A파일명_업로드용.xlsx

Ctrl 또는 Shift를 이용해 여러 파일을 선택하세요.

A2가 품번코드[수정불가]인 새 양식을 선택하세요.

프로그램을 준비하고 있습니다.

첫 번째 시트 / 제목 2행 / 데이터 4행부터를 사용합니다. 중간 빈 행은 압축하지 않습니다. 미리보기는 파일당 최대 100개 옵션이며 결과에는 전체 옵션을 포함합니다.

수정 대상은 옵션 행의 A~E열 및 L~M열입니다. F~K열과 다른 영역은 유지합니다. 결과와 대응하지 않는 행에 기존 데이터가 남으면 임의로 삭제하지 않고 중단합니다.

검증에 실패한 A파일은 ZIP의 결과 엑셀에서 제외됩니다. 처리결과.txt에 성공·실패 및 이유를 기록합니다. 동일 결과 파일명에는 (2) 등을 붙입니다.

파일별 B양식은 원본에서 독립적으로 만듭니다. 이번 작업에서 이미 생성한 품번코드·새 단품코드 조합과 중복되면 나중 파일을 실패 처리합니다.

파일은 브라우저에서 처리하며 서버로 전송하지 않습니다. 라이브러리 로딩에는 인터넷 연결이 필요합니다. 엑셀 검증 통과와 외부 서비스의 업로드 수용 여부는 별개입니다. 원본 파일은 보관하고 처음 생성한 결과는 Excel에서 확인하세요.
